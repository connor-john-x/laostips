# LaosTips 变现方案

本文档说明如何把 LaosTips 从「有流量的内容站」变成「有收入的产品」。核心原则：
**先把内容与流量做起来，再逐步叠加变现方式，避免过早伤害用户体验。**

---

## 一、变现前的准备（0 → 1）

| 阶段 | 目标 | 关键动作 |
| --- | --- | --- |
| 起步期（0–3 个月） | 积累 30–50 篇高质量文章 | 主攻搜索需求明确的签证、交通、费用、找工作关键词 |
| 成长期（3–12 个月） | 月访问 1 万–10 万 PV | 多语言 SEO、社交媒体分发、建立邮件列表 |
| 变现期（6 个月+） | 稳定收入 | 广告 + 联盟 + 赞助 + 服务，多腿走路 |

> 建议先用 **Cloudflare Web Analytics**（免费、隐私友好）看数据，再决定投放平台。
> 在 `src/consts.ts` 中把 `CF_ANALYTICS_TOKEN` 填上即可启用。

---

## 二、主要变现方式

### 1. 展示广告（被动收入，最容易起步）

- **Google AdSense**：门槛最低，适合起步。
  - 需要：独立域名、原创内容、隐私政策页（本站已有 `/privacy/`）。
  - 本站已在 `AdSlot.astro` 预留 4 种广告位：`banner`、`in-article`、`sidebar`、`footer`。
  - 启用方法：
    1. 申请通过后拿到 `ca-pub-xxxx`。
    2. 在 `.env` 或 Cloudflare 环境变量中设置 `PUBLIC_ADSENSE_CLIENT=ca-pub-xxxx`。
    3. 把 `src/consts.ts` 里的 `ADSENSE_ENABLED` 改为 `true`。
    4. 在各页面 `<AdSlot slot="你的广告单元ID" />` 填入 `data-ad-slot`。
  - 缺点：中文旅行内容的单价（RPM）偏低，通常 1–5 美元/千次展示。
- **替代/进阶广告联盟**：
  - 英文流量起来后可用 **Ezoic / Mediavine / Raptive (AdThrive)**，单价更高。
  - 面向中文用户可考虑 **百度联盟、穿山甲（字节）**。
  - 老挝本地商家（酒店、旅行社、换汇、电话卡）可**直接售卖广告位**，单价往往高于联盟。

### 2. 联盟营销 / 带货（佣金收入）

在文章里推荐真实使用的产品，通过专属链接赚佣金，用户价格不变。

| 品类 | 常见平台 | 备注 |
| --- | --- | --- |
| 酒店 | Booking.com、Agoda、Airbnb | 佣金约 3–7% |
| 机票/比价 | Skyscanner、Kiwi、Trip.com | 佣金较低但量大 |
| 当地玩乐 | Klook、GetYourGuide、Viator | 东南亚产品丰富 |
| 交通票 | 12Go Asia | 巴士/火车/船票 |
| 旅行保险 | SafetyWing、World Nomads | 客单价高，佣金可观 |
| eSIM / 电话卡 | Airalo、Holafly | 复购与转化好 |
| 换汇/转账 | Wise、Revolut | 面向长期居住者 |

**做法**：写「老挝电话卡怎么选」「老挝旅行保险对比」这类评测文，自然植入链接。
**合规**：在页脚或文章顶部声明「含联盟链接」，本站 `/privacy/` 已包含说明。

### 3. 赞助文章 / 软文（单价最高）

- 目标客户：中资企业招聘、语言学校、房产中介、旅行社、保险公司、签证代办。
- 形式：品牌故事、产品测评、招聘合作，可长期保留并被搜索收录。
- 定价参考：**100–500 美元/篇**，取决于品牌与篇幅。
- 本站已有 `/advertise/` 招商页（含价格区间与联系方式），可直接发给潜在客户。

### 4. 广告位直售

- 首页顶部、文章内、侧边栏打包售卖。
- 参考定价：**50–300 美元/月/位**，流量越大越贵。
- 可用 Google Ad Manager 或简单的图片链接 + 自行统计展示。

### 5. 邮件通讯赞助

- 用 Buttondown / ConvertKit / MailerLite 收集订阅（本站已有订阅组件）。
- 订阅量到几千后，可在每期邮件顶部出售赞助位，**50–200 美元/次**。
- 在 `src/consts.ts` 设置 `NEWSLETTER_ACTION` 指向你的邮件服务表单地址。

### 6. 增值服务（客单价最高，但要投入人力）

- 签证代办咨询、行程定制、接机、翻译陪同、找房/找工作咨询。
- 付费社群（微信/Telegram）：入群费或年费。
- 付费电子书 / 专栏：「老挝工作避坑指南」「老挝创业手册」。
- 商家付费收录：老挝餐厅、酒店、中介黄页目录。

## 三、流量从哪里来

1. **搜索 SEO**：主攻「老挝签证」「老挝工作签证」「万象生活成本」「中老铁路」等高意图关键词。
2. **中文社交**：小红书、抖音、微信公众号、B 站——旅游与出海内容传播快。
3. **英文/泰文/老挝文**：Facebook 群组、YouTube、TikTok。
4. **问答与论坛**：Reddit r/laos、Quora、贴吧。
5. **邮件列表**：把一次性访客变成可反复触达的资产。

---

## 四、合规与注意事项

- 广告与赞助内容必须明确标注「广告 / 赞助」（本站 `AdSlot` 默认显示 `ads.label`）。
- 保持 `/privacy/` 隐私政策更新，说明 Cookie、广告与分析的使用。
- 联盟链接需做披露，避免误导读者。
- 收入涉及税务与收款（PayPal、Wise、Stripe），请按所在地法规申报。

---

## 五、推荐的收入组合（示例）

| 来源 | 占比建议 | 特点 |
| --- | --- | --- |
| 展示广告 | 20% | 被动、稳定、单价低 |
| 联盟营销 | 30% | 与内容强相关，可持续 |
| 赞助/软文 | 30% | 单价高，需商务拓展 |
| 增值服务 | 20% | 客单价最高，最花时间 |

**执行顺序建议**：内容 → SEO → 邮件列表 → AdSense → 联盟 → 直售广告/赞助 → 服务。

## 六、代码里已经预留好的变现入口

| 文件 | 作用 |
| --- | --- |
